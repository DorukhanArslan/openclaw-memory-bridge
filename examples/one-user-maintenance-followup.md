# One-User Maintenance Follow-Up

This fixed, separately authorized continuation completes the remaining maintenance and restart checks in the original fictional user's retained corpus. It does not replay the consumed lifecycle attempt or replace its partial report.

```sh
npm run acceptance:one-user-followup
```

The command takes no arguments. It requires the exact retained prior-day attempt, an unused follow-up directory, the configured OpenRouter credential, current public pricing, and fresh native quota metadata. It is not an automatic CI or installation step.
